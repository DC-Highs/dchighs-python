# Changelog

## 0.1.0

First release. Python port of the DC Highs Dragon City libraries.

- `dc_core` (required): enums, game settings, validation tools and calculators.
- Optional modules, installed through extras: `dc_localization`, `dc_statistics`, `dc_assets`, `dc_config`,
  `dc_config_mapper` and `dc_client_state`.
- `dc_assets` can download old versions of the Flash client (`FlashClientDownloader`).
